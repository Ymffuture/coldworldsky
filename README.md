
# Quorvex Institute

**Website:** [Quorvex institute](https://quorvexinstitute.vercel.app)  
Quorvex Institute is a private education platform offering expert tutoring, curated courses, and academic support in sciences, technology, and design.

## 🔑 Key Features

- **Subject Tutoring**: Life Sciences, Math, Physical Science
- **Career Courses**: Web Development, Data Science, UI/UX
- **AI Tutor**: Smart learning assistant with interactive support
- **Student Dashboard**: Personalized login and resource access
- **Resources**: Calendar, quote-of-the-day, responsive UI

## 🧰 Tech Stack

- **Frontend**: React.js, TailwindCSS, React Router
- **Backend**: Firebase (Auth, Firestore, Storage)
- **UI**: Bulma CSS, React Icons, Framer Motion
- **Hosting**: Vercel
